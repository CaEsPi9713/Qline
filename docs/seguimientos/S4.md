## 4. Deuda técnica y decisiones abiertas

Lo conocido que S3 deja sin resolver. Cada punto indica por qué importa; no son errores nuevos sino límites aceptados en S3 o cosas que el equipo debe decidir.

### 4.1 Acceso y seguridad

| Tema | Detalle | Qué hacer |
|---|---|---|
| Pantalla de sala y quiosco detrás de la contraseña de Apache | Solo las rutas del QR son públicas (D-22). Si la pantalla de sala usa WebSocket (`/ws/eventos`) y el navegador no reenvía las credenciales, puede pedir la contraseña en bucle como pasó con el QR | Probarlo en la pantalla real; decidir si el dispositivo se autentica una vez o si se exponen `/api/llamados` y `/ws/eventos` (no llevan datos personales, pero sí códigos de turno) |
| Regla `/static/` pública en cualquier parte de la ruta | El `.htaccess` deja pasar cualquier URL que contenga `/static/`; la aplicación solo sirve `static/style.css` | Acotar la regla al prefijo real de despliegue si se quiere más estricto |
| El `qr_token` no caduca | Un enlace de QR sigue funcionando indefinidamente, también para turnos ya atendidos | Decidir una vigencia (por ejemplo, horas desde el estado final) o aceptar el comportamiento y documentarlo |
| Protección del sitio con `.htpasswd` de la cuenta del curso | La relajación para el QR (D-22) no se consultó con el profesor | Confirmarlo antes de la exposición |

### 4.2 Datos y consultas

| Tema | Detalle | Qué hacer |
|---|---|---|
| ~~Fechas del historial exportado sin zona horaria~~ | **Resuelto** (decisión D-23): la API y las descargas entregan `2026-10-27T01:12:49.757Z` y las pantallas muestran la hora local | Verificar el formato en el servidor |
| La exportación del historial carga todo en memoria | `exportar_historial_turnos` usa `limite=0` y devuelve una sola lista; con cientos de registros no importa, con muchos miles sí | Paginar o escribir en *streaming* si el volumen crece |
| La consulta por código solo admite `A-NNN` | `consultar_turno` rechaza series como `S-NNN` (datos sintéticos), que sí existen en MongoDB e historial | Decidir si la consulta debe aceptar otras series |
| Mediciones con 554 turnos | Las diferencias de tiempo entre índice y recorrido completo son pequeñas (1,6 a 1,8 veces) | Repetir con más datos si se quiere mostrar el efecto del índice en tiempo |
| Hipótesis de S1 no cumplida | Redis resultó 2,8 a 3,7 veces más rápido, con mejora del 64 % al 73 %, no el 85 % esperado | Presentarlo tal cual en la exposición, con la explicación de la bitácora |

### 4.3 Operación

| Tema | Detalle | Qué hacer |
|---|---|---|
| Barrido de abandono por *worker* | Con varios *workers* de Gunicorn hay un barrido por *worker*; es seguro por diseño (D-17 y D-18) pero no se midió | Verificar con la configuración real del servicio |
| Rehidratación y llamadas simultáneas | Si un turno se llama justo mientras se reencola, queda un código obsoleto en la cola (D-20) | Ejecutar `rehidratar_cola` con la atención detenida; o diseñar un bloqueo si se quisiera automatizar |
| Sin `EVAL`/Lua | No se verificó que el Redis compartido lo permita; la reserva de ventanilla usa `SET NX` (D-03) | Mantener el diseño actual salvo que haga falta atomicidad adicional |
| Si Redis falla después de abandonar un turno, la ventanilla puede conservar su clave | La repara el siguiente llamado al contrastar con MongoDB (D-03) | Aceptado; documentarlo en el README de operación |
| `docs/evidencia/` generada en una sola ejecución | Los informes reflejan una ejecución en el servidor del 26 y 27/10/2026 | Regenerarlos si cambia el código o los datos antes del release |

## 5. Variables de entorno que el README debe explicar

| Variable | Para qué sirve | Valor sugerido |
|---|---|---|
| `MONGO_*` | Conexión a MongoDB | Ver `.env.example` |
| `REDIS_*` | Conexión a Redis | Ver `.env.example` |
| `BASE_PATH` | Ruta bajo la que Apache publica la aplicación | Debe coincidir con el despliegue |
| `ZONA_HORARIA` | Zona en la que las pantallas muestran fechas y horas | `America/Costa_Rica` (por defecto); nombre IANA |
| `PUBLIC_BASE_URL` | Dominio público para el enlace del QR | `https://grupo2.crnube.net`; nunca `localhost` |
| `BARRIDO_ABANDONO` | Activa el abandono automático | `1` (o ausente); `0` lo apaga |
| `BARRIDO_INTERVALO_SEG` | Segundos entre pasadas del barrido | `10` |
